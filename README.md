# Комплект для товара: стикер + бирка (print-ready)

Кейс из двух демо-продуктов: один персонаж — «кот со штангой» — на стикере и бирке. Показывает полный путь от описания словами до файлов, которые печатная типография принимает без переделок.

Печатаем не мы — отдаём готовые файлы, тираж и материал заказчик выбирает сам.

## Что в комплекте

**Стикер die-cut, 50×50 мм.** Арт нарисован нейросетью по текстовому описанию, контурный рез CutContour и TrimBox 50×50 мм — сервис отдаёт такой PDF сам (каталогный продукт).

**Бирка 50×90 мм** — тот же кот, форма со скруглёнными углами R3 и вырезом Ø3,5 мм под шнур. Для бирки (кастомный размер) сервис print-PDF не отдаёт, поэтому файл собран собственным скриптом:

- вылет (bleed) 2 мм: страница 54×94 мм, TrimBox ровно 50×90;
- контур реза отдельным векторным слоем #FF00FF 0,2 мм в группе plate-CUT;
- метки TrimBox/BleedBox прописаны прямо в PDF;
- разрешение арта 325 dpi (12,8 px/мм), картон 350gsm, CMYK.

## Честные границы

- Арт — нейросеть по описанию; доведение до печати — скрипт, который считает размеры по миллиметрам, не на глаз.
- ИИ-арт не даёт юридического эксклюзива: обещаем файл, а не монополию на картинку.
- Перед передачей в типографию макет проверяем сами — это и есть работа: размер, вылет, линия реза, метки.
- Живой тираж по этим файлам ещё не гонялся: рез по мадженте и TrimBox — стандарт, приняты ли они конкретной типографией, проверяется на первом тираже.

## Как посмотреть

Открыть оба PDF в любом просмотрщике — размер страницы и TrimBox видны в свойствах документа. Стикер и бирка поставлены рядом не случайно: один промпт-стиль держит двух персонажей одного бренда.
